Four short guides

From shortlist to parcel

For each item, record the seller, variant, size in centimeters and the date you checked it. Mark anything that needs a follow-up.

01 · Sourcing

Verify PinguBuy product links

Keep the original Weidian product link, Taobao listing URL or 1688 item page next to any agent link. Record the marketplace item ID and seller name so you can identify the right listing if a saved link stops working.

Check live stock for the selected size and color. Save a second seller only after confirming the product model and variant. Mark old or broken product links as unverified until you can match them.

02 · Fit

Compare the seller’s size chart

For a sneaker size comparison, measure both feet and check the longer foot against the seller’s foot-length chart. Ask whether a centimeter value refers to foot length or the removable insole.

Lay a garment you like flat. Compare chest width, shoulder width and sleeve length for a hoodie, or waist width and inseam for trousers. For a cap, check the head circumference and how far the closure adjusts.

03 · Inspection

Review PinguBuy QC photos

If warehouse quality-control photos are available, look for a readable size tag, a full view of the item and close-ups of seams or hardware. For sneakers, ask for side and outsole photos. For a bracelet, ask for a close-up of the clasp and confirm its inner circumference.

Compare the photos with your selected variant. If you see a mismatch or visible damage, save the photo and check the return request deadline before approving shipment.

04 · Delivery

Compare PinguBuy shipping costs

Use the same destination postcode when comparing international shipping quotes. Record the packed parcel dimensions and actual weight. Check how each shipping line calculates volumetric weight and whether parcel consolidation changes the chargeable weight.

Keep domestic delivery, packing fees, currency conversion and any applicable import charges separate in your estimate. Confirm the warehouse storage deadline while you wait for the last item to arrive.

PinguBuy spreadsheet FAQ

What is a PinguBuy spreadsheet?

It is a curated list of product links used to discover and compare items before ordering through a shopping agent. Open the original listing to confirm the seller, selected variant and current availability.

What should I do if a PinguBuy product link is broken?

Look for the original marketplace link or item ID. If you find a working listing, confirm the seller and variant before saving it. Mark the row as unverified if you cannot match it.

How should I compare shoe and clothing sizes?

Compare measurements in centimeters with the seller's size chart. Use foot length for shoes and measure a garment you already own for chest width, sleeve length or inseam.

What can warehouse QC photos tell me?

Quality-control photos can help confirm the selected color, size tag and visible condition. Use them to flag mismatches or damage, and seek independent verification for authenticity.

How do I estimate the total cost of an international parcel?

Add the item subtotal, domestic shipping, applicable handling fees and the international shipping quote. Check the chargeable weight, currency conversion and any import charges that apply to your destination.
